# AOS UNIVERSE — Engineering Toolchain Binding v0.1

## Principle

Tooling is implementation support. Tooling is not AOS.

## Binding Matrix

| Tool surface | Role | AOS position |
|---|---|---|
| GitHub | Repository / version evidence | Bound |
| Superpowers | Development methodology | Bound / installed |
| Vercel | Deployment surface | Available / not activated |
| Linear | Planning / work tracking | Bound / installed |
| Notion | Documentation / knowledge support | Bound / installed |
| OpenAI Developers | Development guidance | Bound / installed |
| Inngest | Durable execution candidate | Selected / not conformant |
| AppDeploy | Deployment candidate | Available / not bound |
| Supabase | Persistence candidate | Available / not bound |

## Rule

A tool may implement or support a capability only after its required contract, adapter boundary, authorization, evidence requirements, and validation criteria are satisfied.

No tool is allowed to redefine the AOS Constitution or Universal Architecture.
